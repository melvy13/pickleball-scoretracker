What should this file look like?

The file needs a teams array and a pairs array. Every team must have exactly 3 pairs — one at each seed (1, 2, and 3).

  • teams[].id — unique short id, e.g. "A"
  • teams[].name — display name, e.g. "Thunderbolts"
  • pairs[].id — unique pair id, e.g. "A1"
  • pairs[].team — must match a team id above, e.g. "A"
  • pairs[].seed — 1, 2, or 3
  • pairs[].type — "XD" or "WD"
  • pairs[].players — array of exactly 2 names
  • pairs[].voided — true or false (normally false)

Optional — controls the starting match order in Score Entry:

  • fixtureOrder — array of "teamId-teamId" pairings in the order you want them played, e.g. ["C-E", "A-F", "B-G"]. Every team pairing must appear exactly once. If left out, fixtures default to a standard order.
